# 🌅 Sundown Studio Clone

A modern and interactive frontend clone inspired by the beautiful design of Sundown Studio.  
This project focuses on smooth animations, immersive scrolling, creative layouts, and engaging user interactions using modern web technologies.

---

## 🚀 Overview

The Sundown Studio Clone is a visually rich web project created to practice advanced frontend development concepts such as:

- Smooth scrolling
- GSAP animations
- Interactive hover effects
- Responsive layouts
- Modern UI/UX design
- Scroll-based animations

The goal of this project is to recreate a premium website experience while improving animation and frontend development skills.

---

## ✨ Features

- 🎬 Smooth scrolling using Locomotive Scroll
- ⚡ GSAP powered animations
- 🖱️ Custom cursor interactions
- 🖼️ Image hover preview effects
- 🎥 Embedded video section
- 🎨 Modern and clean UI
- 🔥 Scroll-triggered animations
- 💫 Interactive page elements

---

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **JavaScript**
- **GSAP**
- **Locomotive Scroll**
